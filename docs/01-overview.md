## 🧠 The Idea

As a Junior Software Developer with an MSc in Computer Science, I needed more than a static resume or a simple GitHub profile. I needed a platform that:

1. **Shows what I can build** — not just what I know on paper
2. **Works everywhere** — web, mobile, and desktop from one codebase
3. **Is fully under my control** — no third-party portfolio builders, no templates

The **Nashrah Portfolio Suite** is a custom-built, production-grade portfolio platform that serves two purposes simultaneously:

- **Real-world portfolio** — Employers and clients can visit the web app or mobile app to explore my projects, skills, experience, certifications, and blog
- **Technical showcase** — The codebase itself demonstrates Clean Architecture, cross-platform development, REST API design, and modern web/mobile engineering

## 🏗️ What Makes This Different

Unlike a simple portfolio website, this suite is a **full product**:

```
Most developer portfolios:    Nashrah Portfolio Suite:
─────────────────────────     ─────────────────────────────────
Static HTML/CSS site     →    Full-stack ecosystem (API + Web + Mobile)
Hardcoded content        →    CMS-driven admin panel
Web only                 →    Web + Mobile (Android + Windows)
No backend               →    ASP.NET Core API with JWT auth
Template-based           →    Custom Clean Architecture
```

## 🗺️ Project Scope

### In Scope (Building Now)
- ✅ ASP.NET Core REST API with Clean Architecture
- ✅ Next.js web app (visitor-facing + admin panel)
- ✅ .NET MAUI mobile app (Android + Windows)
- ✅ SQL Server database with EF Core Code-First
- ✅ JWT authentication for admin access
- ✅ Dynamic project, skill, experience, blog management
- ✅ Contact form with message storage

### Out of Scope (Not Building)
- ❌ Multi-tenant support (this is a personal portfolio)
- ❌ E-commerce or payment processing
- ❌ Native iOS build (planned later, not in scope now)
- ❌ CMS for anonymous public users (admin-only content management)
